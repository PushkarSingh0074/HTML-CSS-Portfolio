# Pushkar Singh — HTML & CSS Portfolio

EWB Courses HTML & CSS Internship project: a responsive personal portfolio built with **HTML5 and CSS3 only** (no JavaScript, frameworks or libraries).

## Project description

This is a responsive personal portfolio website that introduces me as a Data Science and Machine Learning student and presents my skills, projects and contact details. It is built with semantic HTML5 (`header`, `nav`, `main`, `section`, `article`, `footer`) and a single `style.css` that uses CSS variables, Flexbox and CSS Grid, and media queries for tablet and mobile layouts. All interaction and animation is pure CSS: staggered hero entrance, scroll-reveal sections (CSS scroll-driven animations), animated project logos, hover/focus states on every button, link and card, and expandable project case studies using the native `<details>` element. A light/dark theme switch works through a checkbox and the CSS `:has()` selector, and all motion is turned off for users who prefer reduced motion.

## Sections

Header/Navigation · Hero (Home) · About Me (bio, education, career interests) · Skills (6 groups, 35+ skills) · Projects (3 project cards) · Contact · Footer
